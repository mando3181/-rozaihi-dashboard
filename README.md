# سلطان الرزيحي جروب — الداشبورد الموحد 2026

- `index.html` — الداشبورد الموحد (الشركات الخمس + قطاعا التجزئة والكافيهات + التدفقات النقدية). ملف واحد مستقل يتضمن داخله الداشبوردين.
- `retail/index.html` — داشبورد قطاع التجزئة منفردًا (مع مديول التدفقات النقدية).
- `nakahat/index.html` — داشبورد نكهات منفردًا (مع مديول التدفقات النقدية).

## التشغيل
افتح `index.html` في المتصفح (يحتاج إنترنت لتحميل Chart.js وFont Awesome وخط Tajawal)، أو فعّل GitHub Pages (Branch: main / root).

## تنبيه
الملفات تحتوي بيانات مالية فعلية للمجموعة. استخدم مستودعًا **خاصًا (Private)**، ولا تفعّل Pages إلا إن كان النشر العلني مقبولًا.

## ملاحظة
تدفقات شركة ريال البركة النقدية لم تُدرج بعد (لم يصل ملفها).
